# Tiny MLの言語仕様

小さなML風の式言語です。書籍に登場する言語の完全な再現ではありません。実装対象は以下に固定し、拡張は基本部分の完成後に行えます。

## 字句

- 整数：ASCII数字の1文字以上の列。先頭ゼロを許す10進数。値の範囲は `0..=9223372036854775807`。
- 識別子：`[A-Za-z_][A-Za-z0-9_]*`。大文字小文字を区別し、単独の `_` も普通の名前。
- 予約語：`true false if then else let in fun`。`ifx` や `letter` は識別子。
- 記号：`-> = + - * / < ( )`。`->` は1トークン。
- 空白：ASCIIのスペース・タブ・CR・LFを読み飛ばす。
- コメント、Unicode識別子、文字列、浮動小数点は対象外。不明な文字は `UnexpectedCharacter`。
- 各TokenにUTF-8バイト単位の半開区間 `Span { start, end }` を付ける。不正なUnicode文字の位置は、その文字全体のバイト区間を指す。
- 末尾に `Eof` を必ず1つ付ける。位置は `source.len()..source.len()`。空入力もEofだけを返す。
- 数値トークンの範囲を超えた場合は `IntegerOutOfRange`。

`-` は整数に含めず、単項マイナスまたは減算として構文解析します。このため `-9223372036854775808` の数字部分は字句エラーです。最小値は `-9223372036854775807 - 1` として表現できます。これは字句と単項マイナスを分離した、このひな形の仕様です。

## 文法

`{ ... }` は0回以上、`[ ... ]` は省略可能、`|` は選択です。

```ebnf
program     = expr, EOF ;
expr        = "let", IDENT, "=", expr, "in", expr
            | "if", expr, "then", expr, "else", expr
            | "fun", IDENT, "->", expr
            | comparison ;
comparison  = additive, [ "<", additive ] ;
additive    = product, { ("+" | "-"), product } ;
product     = unary, { ("*" | "/"), unary } ;
unary       = "-", unary | application ;
application = atom, { atom } ;
atom        = INT | "true" | "false" | IDENT | "(", expr, ")" ;
```

- 優先順位は強い順に、括弧、関数適用、単項マイナス、乗除、加減、比較。
- 関数適用と算術演算は左結合。`f x y` は `(f x) y`、`8 - 3 - 1` は `(8 - 3) - 1`。
- 比較は連鎖不可。`1 < 2 < 3` は構文エラー。
- `f -1` は減算。負数を渡すときは `f (-1)`。`-f x` は `-(f x)`。
- `fun` は1引数。複数引数は `fun x -> fun y -> ...`。
- `let f x = ...` の糖衣構文、型注釈、再帰、リスト、タプル、パターンマッチは対象外。
- `if` / `let` / `fun` を演算の被演算子や関数の引数に使う場合は、必要に応じて括弧で囲む。
- 入力は1つの式とEOFに限る。末尾の余分なトークン、空の式、欠落した括弧やキーワードは `UnexpectedToken`。
- `parse` に空のトークン列やEOFのない列を渡してもpanicせず、`UnexpectedToken` を返す。

ASTの各ノードのSpanは、その式を構成する最初のトークンの開始位置から最後のトークンの終了位置までです。先頭・末尾の空白は含みません。括弧用ノードは作らず、括弧内の式のSpanを括弧を含む区間へ広げます。`-(1 + 2)` なら、Negateが `0..8`、その子のBinaryが `1..8` です。

## 型

型は `int`、`bool`、型変数、関数型です。関数型の矢印は右結合で表記します。`infer` は空の型環境から開始し、自由な型変数を含んでもよい主型 `Type` を返します。型変数番号は呼び出し間・実装間で一致する必要はありません。

- 四則演算と単項マイナスは整数を受け取り、整数を返す。
- `<` は整数2つを受け取り、真偽値を返す。
- `if` の条件は真偽値、両分岐は同じ型。
- 関数の引数は関数本体の中で単相として扱う。
- `let` は非再帰。定義式では新しい束縛を参照できない。同名の外側の束縛があれば参照できる。
- `let` で多相な型スキームを許す。環境に自由に現れる型変数は量化しない。
- 無限型は許さない。

| 式 | 期待する型 |
| --- | --- |
| `42` | `int` |
| `1 < 2` | `bool` |
| `fun x -> x` | `'a -> 'a` |
| `fun f -> fun x -> f x` | `('a -> 'b) -> 'a -> 'b` |
| `let id = fun x -> x in let a = id 42 in id true` | `bool` |
| `1 + true` | `TypeMismatch` |
| `fun x -> x x` | `InfiniteType` |
| `missing` | `UnboundVariable` |

## 評価

`eval` は空の値環境から始めます。型推論を内部から呼び出す必要はありません。

- 値は整数・真偽値・クロージャ。関数は定義時の環境を捕捉する静的スコープ。
- 関数適用は関数側、引数側の順に評価する値呼び。両方を評価した後、関数側がクロージャでなければ `NotCallable`。
- 二項演算は左辺、右辺の順に評価した後、オペランドの型を確認する。先に失敗した評価のエラーを返す。
- `let` は定義式を評価してから本体を評価する。
- `if` は条件を評価し、真偽値であることを確認して、選択した分岐だけを評価する。
- 整数演算は `i64` の範囲。オーバーフローは `Overflow` とし、debug/releaseで挙動を変えない。
- 整数の除算は0方向に切り捨てる。`-7 / 2` は `-3`。ゼロ除算は `DivisionByZero`、`i64::MIN / -1` は `Overflow`。
- 未束縛変数は `UnboundVariable`、演算や条件の値の種類が違う場合は `TypeMismatch`。

| 式 | 期待する値 |
| --- | --- |
| `1 + 2 * 3` | `7` |
| `if true then 42 else 1 / 0` | `42` |
| `(fun x -> x) 42` | `42` |
| `let x = 10 in let f = fun y -> x + y in let x = 100 in f 2` | `12` |
| `fun x -> x` | クロージャ（表示は `<fun>`） |

## エラーの契約

エラーは `Diagnostic { stage, kind, message, span }` です。`stage` はその処理段階、`kind` は上で示した分類、`message` は自分で書く説明です。テストは説明文の完全一致を要求しません。

位置が分かる場合は `Some(Span)` を入れます。lexerは不正文字や数値、parserは最初の予期しないトークン（不足時はEOF）、型推論・評価は問題の式の位置を使います。手作りASTのテストでは位置を検証しません。

未実装段階だけは `Diagnostic::unimplemented(Stage::...)` を返します。部分実装中も未対応の構文にこれを返すと、Web画面で通常のエラーと区別できます。
